### Priyanshu Vijay Portfolio

A modern personal portfolio built with Next.js for showcasing engineering work, creative projects, research, and professional experience.


## Overview

This project is a polished one-page portfolio with an additional gallery route, designed to present the work of Priyanshu Vijay across:

- AI/ML engineering
- data science and analytics
- full-stack web development
- game and desktop application development
- creative art and visual design

The portfolio combines strong storytelling, smooth motion, dark/light theming, and interactive UI elements to make the work feel premium and engaging.

## Features

- Hero section with premium landing experience
- About and academic highlights
- Skills and technology stack overview
- Experience timeline and projects showcase
- Credentials and certifications display
- Research section with documentation and impact details
- Creative gallery and art showcase
- Contact form integration
- AI-powered portfolio assistant powered by Gemini
- Light/dark/system theme support
- Responsive design for desktop and mobile

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- React Icons
- Three.js / React Three Fiber
- EmailJS
- Google Generative AI

### Notes

- The contact form uses EmailJS.
- The portfolio assistant uses Gemini to answer questions based on the site content.
